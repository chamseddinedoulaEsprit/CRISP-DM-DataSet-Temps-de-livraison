🟢 Guide de Démarrage - Delivery Prediction

Option 1 : Manuel (le plus simple sous Windows)

Ouvre PowerShell et va dans ton dossier :

cd "C:\Users\chams\OneDrive\Bureau\projetPIDEV\CRISP-DM-DataSet-Temps-de-livraison"

Installe les dépendances :

pip install -r requirements.txt

Lance l’application :

python run.py

➡️ L’API sera disponible ici : http://localhost:5000

Notes :

  • Assurez-vous que les fichiers lightgbm_model.pkl et dbscan_model.pkl sont dans le même dossier que run.py.
  • Le mode debug est activé, pratique pour le développement.
  • Pour arrêter l’application, pressez CTRL + C dans PowerShell.
