Objectifs Métiers (Business Objectives - BO) - ORDRE CORRIGÉ

BO1 : Réduction de dimensionnalité – Simplifier les données en résumant les informations clés du dataset en un nombre réduit de variables, facilitant les analyses futures sans perte significative d'information et améliorant les performances des modèles.
BO2 : Prédire le temps de livraison – Estimer précisément combien de temps prendra chaque livraison pour fournir un horaire fiable aux clients, réduisant les frustrations et améliorant la satisfaction globale.
BO3 : Segmentation des commandes – Regrouper les commandes en groupes similaires pour mieux organiser et assigner les livreurs, améliorant l'efficacité logistique.

Objectifs Data Science

Pour BO1 : Réduction de dimensionnalité sur features numériques (subtotal, total_items, num_distinct_items, etc.) avec test systématique de k ∈ [1,11] pour conserver 85-95% de variance ; algorithmes : PCA, t-SNE ; méthode : seuil 90% variance + méthode du coude ; prétraitement : StandardScaler, imputation.
Pour BO2 : Régression supervisée pour prédire la variable cible "temps de livraison" (différence en minutes entre actual_delivery_time et created_at), avec features enrichies incluant météo et temporelles ; modèles : régression linéaire, random forest, gradient boosting, XGBoost, LightGBM ; métriques : MAE, RMSE, R², MAPE.
Pour BO3 : Clustering non supervisé pour segmenter les commandes avec test systématique de k ∈ [2,11] via features mixtes (market_id, total_items, delivery_duration_min, variables temporelles/météo) ; algorithmes : K-means (StandardScaler), DBSCAN (MinMaxScaler) ; validation : elbow method, silhouette score, Calinski-Harabasz, Davies-Bouldin.
